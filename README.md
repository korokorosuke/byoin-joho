</div>

# 概要
各厚生局のホームページから、最新の病院情報を取得します。

# 機能
- データを取得し、DB(sqlite)に書き込む
- 取得したデータを、csvに出力
- 取得したデータの、ビューアでの検索

# 使い方
## 準備
```bash
bun install
```
## 実行
```bash
bun run start
```

## 実行（引数あり）
```bash
bun run start arg1 arg2
```

### 実行時パラメータ
- arg1: 1:データ取得 2:データ出力 3:ビューア起動
- arg1が「1」の時  
arg2: 1:九州 2:四国 3:中国 4:近畿 5:東海 6:関東 7:東北 8:北海道 9:全部
- arg1が「2」の時  
arg2: 1:csv出力
